# 🍲 Mijou — Qu’est-ce qu’on cuisine aujourd’hui ?

**Mijou** est une application mobile développée avec Flutter qui aide à trouver quoi cuisiner à partir des ingrédients disponibles dans son réfrigérateur.

Le principe est simple : *« Voilà ce que j’ai, dis-moi quoi cuisiner ! »* 🥑

L’application propose une expérience intuitive et un design inspiré d’une maquette Figma comprenant 8 écrans.

## ✨ Fonctionnalités

- 🏠 **Accueil** — Découvrir l’application et accéder aux fonctionnalités.
- 🍽️ **Menu** — Explorer les possibilités culinaires.
- 🧊 **Mon frigo** — Sélectionner les ingrédients disponibles.
- 🔎 **Résultats** — Découvrir des recettes adaptées aux ingrédients sélectionnés.
- 📖 **Détail d’une recette** — Consulter les ingrédients et les étapes de préparation.
- 👩‍🍳 **Mode cuisine** — Suivre les instructions et utiliser un minuteur.
- ❤️ **Favoris** — Retrouver ses recettes préférées.
- 🛒 **Liste de courses** — Organiser les ingrédients à acheter.

## 🛠️ Technologies utilisées

- **Flutter**
- **Dart**
- **Figma** — Maquette et conception des interfaces

## 🚀 Lancer le projet

Assurez-vous d’avoir Flutter installé, puis exécutez les commandes suivantes depuis le répertoire du projet :

```bash
flutter pub get
flutter run
```

## 🎯 Objectif du projet

Créer une application mobile agréable et simple à utiliser pour faciliter le choix des repas, valoriser les ingrédients déjà disponibles et accompagner l’utilisateur pendant la préparation des recettes.

*Fait avec ❤️ et Flutter pour rendre la cuisine plus simple au quotidien.*

**NB :** Cette application est encore en cours de développement. Je continue d’y ajouter de nouvelles fonctionnalités, d’explorer de nouvelles idées et de l’améliorer au fil du temps. Ce projet est bien plus qu’une simple application : c’est un espace personnel qui réunit ma créativité et mon amour pour la cuisine. J’adore son concept, son ambiance et sa palette de couleurs. C’est mon petit univers, un espace de détente où je peux laisser libre cours à mon imagination, explorer de nouvelles idées culinaires et créer une expérience qui me ressemble. 💚🍲
